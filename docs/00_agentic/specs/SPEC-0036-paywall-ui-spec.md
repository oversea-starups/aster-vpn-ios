# SPEC-0036 — Paywall UI 尺寸规范（iOS）

## 结构尺寸
- 顶部标题间距：24
- 卡片间距：12
- CTA 高度：56
- CTA 圆角：28
- 卡片圆角：16
- 底部安全区留白：16

## 文字层级
- Title: 28–32pt, Bold
- Subtitle: 16–18pt, Regular
- Bullet: 15–16pt, Regular
- CTA: 17pt, Semibold
- Footnote: 11–12pt

## 配色
- Primary: 深蓝
- Accent: 青色
- Background: 深灰/黑
- Text: 白 + 80% 白

## 交互
- 卡片选中态：描边 + 轻微高亮
- CTA 点击后进入 Loading 状态
