# SPEC-0014 — QA 测试用例（MVP）

## 连接流程
- [ ] 首次启动 → 点击 Connect → 进入 60s 演示
- [ ] 演示结束 → 自动弹出 Paywall
- [ ] 连接成功状态展示“Protected”
- [ ] 连接失败提示“重试/切换节点”

## 订阅
- [ ] 年付 3 天游试显示正确价格与说明
- [ ] 月付无试用
- [ ] 订阅成功后 Pro 解锁
- [ ] Restore Purchases 可恢复

## 节点
- [ ] 免费节点可连接
- [ ] Pro 节点触发 Paywall
- [ ] 切换节点后状态更新

## 设置/支持
- [ ] Auto‑Reconnect 开关可保存
- [ ] Terms/Privacy 可打开
- [ ] 支持页 FAQ 展示

## 稳定性
- [ ] 弱网下连接失败有提示
- [ ] 断网时连接失败可恢复
- [ ] App 前后台切换保持状态
