# SPEC-0001 — MVP Core Loop (Aster VPN)

## 目标
用最少页面实现“连接 → 状态反馈 → 付费理由”的闭环，为 MRR 提供可验证转化。

## 核心流程（最短闭环）
1. 打开 App → Home
2. 一键连接（Connect）
3. 状态变化（Connecting → Connected）
4. 展示速度/位置与安全提示
5. 演示连接结束（首次一次性 60 秒）→ 触发付费墙（年付试用/订阅）
6. 订阅成功 → Pro 体验

## MVP 必做功能
- 一键连接/断开
- 连接状态与错误提示
- 节点列表（最少 3–5 个核心地区）
- 订阅与恢复购买
- 首屏 60 秒演示连接（一次性）
- 基础设置：自动重连、协议信息（只读）
- 轻量帮助与隐私说明

## 不做（MVP 排除）
- 流媒体解锁/分流/广告拦截
- 复杂测速、家庭共享、企业/团队
- 深度安全检测或系统级防护

## 成功标准
- 连接成功率 ≥ 90%
- 首次连接到可用状态 ≤ 8 秒（基于样本）
- Paywall → Purchase ≥ 0.3%（初期目标）

## 风险与兜底
- 连接失败需给出“重试/切换节点”选项
- 如果节点不可用，默认回退到“最快节点”
