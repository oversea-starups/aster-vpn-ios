# SPEC-0039 — IAA 策略（激励时长）

## 原则
- 只使用用户明确选择的 rewarded ad，不使用自动弹出的 interstitial 或 rewarded interstitial。
- 广告不打断已建立的 VPN，不遮挡连接主按钮，不鼓励点击广告内容。
- Pro 用户不展示广告入口；免费用户明确看到奖励、频控和剩余时长。

## 允许位置
- Home 主连接决策之后的免费时长卡片。
- 独立激励说明页，由用户点击进入并再次确认观看。

## 禁止位置
- Paywall
- 连接中或已连接时自动弹出
- 任何“点击广告支持我们”或诱导广告点击的文案

## 结论
- 激励广告是受控的免费访问方式，订阅仍是无广告、无限时长的主商业模式。
- 具体奖励和频控以 SPEC-0061 与 ADR-0007 为准。
