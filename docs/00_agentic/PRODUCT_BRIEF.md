# Product Brief — Aster VPN

> 目标：面向美区 iOS 用户的轻量 VPN，优先达成 MRR；以“最快的一键连接 + 清晰状态反馈”为核心体验。

## 1. 核心任务（Core Job）
- 一键连接 VPN，在公共网络或不可信网络场景下实现安全访问与隐私保护。

## 2. 目标用户
- 频繁使用公共 Wi‑Fi 的通勤/旅行人群。
- 对隐私与数据安全敏感的普通 iPhone 用户。
- 需要稳定访问与简单操作的非技术用户。

## 3. 核心价值
- **一键连接**：打开即能连，状态清晰可见。
- **稳定与速度优先**：少而精的节点、优先高可用。
- **隐私可信**：本地最小权限 + 明确隐私说明。

## 4. MVP 范围
- 连接/断开、连接状态、节点选择、基础设置、StoreKit 订阅与恢复购买。
- 本版本不集成第三方广告；免费用户在连接前看到清晰的升级理由，Pro 用户获得无限保护时长。
- 不做：流媒体解锁、广告拦截、分流规则、家庭共享、企业管理。

## 5. 付费理由
- 高速节点与更多地区选择。
- 自动重连与更稳定的连接体验。
- 无广告与无限使用时长。

## 6. 关键指标（MRR 导向）
- 试用/付费转化率、首日连接成功率、次日留存、退订率。
- paywall 查看率 → 购买率 → 续订率。
- paywall 入口查看率 → 购买率 → 续订率；首次连接完成率与连接成功率是主要体验指标。
