## 产品真相与 ASO 消息主线

消息主线：`For iPhone users on public Wi‑Fi, protect the connection in one tap without a complicated setup.`

- 主要意图（推断，未宣称搜索量）：VPN、公共 Wi‑Fi 安全、隐私保护。

- 明确移除：`fast`、`best`、`unlimited`（除非对应真实产品权益）、“解锁流媒体”、竞品名称、无依据的无日志/零数据绝对化承诺。

### `free / fast / stable / secure proxy` 判断

- `free`：在美国区搜索结果和竞品标题中非常常见，但大量对应广告支持或免费层产品。Aster 已有真实的一次性 10 分钟首次连接体验，因此可使用 `Free Trial`/本地化“免费试用”；不使用会暗示永久免费或无限线路的 `Free VPN`。
- `fast`、`stable`：竞品大量使用，但属于可验证的性能承诺。当前没有多设备、多网络、DNS/出口和 P95 连接时延证据，不放入可见字段；完成基准测试后再以实验方式加入。
- `secure`、`privacy`、`WiFi security`：与 Aster 的公共 Wi‑Fi 保护核心工作一致，适合放在 Name/Subtitle。
- `Secure Proxy`：`proxy` 是有效的次级扩展词，但不是用户最清晰的主任务表达；保留在 Keywords，不再作为主标题。

## 多语言上线策略

App 内部 UI 的多语言由另一会话处理；本轮已完成 ASC listing 的 15 个语言。每个 Description 均包含订阅条款、一次性 10 分钟试用说明和标准 EULA，但在 UI 本地化和截图完成前，不应把这些语言宣传为完整产品本地化。

下一阶段应按数据优先级逐批完成 UI 与素材本地化；每个语言必须同时完成：

1. App UI String Catalog（Home、Locations、Account、Paywall、错误和恢复购买）。
2. App Name、Subtitle、Keywords、Promotional Text、Description 的本地意图改写。
3. 隐私政策/条款可读性、价格/日期/自动续订说明、截图文字和 Dynamic Type/VoiceOver 验收。
4. 原生审校后再通过 ASC 创建对应 localization；不得仅复制英文 Description。
